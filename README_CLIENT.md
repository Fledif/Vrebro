# Документація проекту VreBRO

## Загальний опис системи
**VreBRO** — це сучасний комплекс для прийому та обробки замовлень, який поєднує в собі Telegram-бота, зручний Міні-додаток (Mini App) для клієнтів та повноцінну Адмін-панель для управління бізнесом.

Система дозволяє приймати замовлення автоматично, вести облік товарів, нараховувати кешбек клієнтам та миттєво сповіщати адміністраторів про нові заявки.

---

## 📱 1. Telegram Міні-додаток (Для клієнтів)
Міні-додаток відкривається прямо всередині Telegram і працює як повноцінний інтернет-магазин.

**Основний функціонал:**
- **Каталог товарів:** Зручний перегляд товарів по категоріях.
- **Кошик:** Можливість додавати товари, змінювати кількість та бачити загальну суму.
- **Оформлення замовлення:** Введення контактних даних, вибір адреси доставки або самовивозу. Вбудована строга валідація українських номерів телефонів (починаються з `0` або `380`) та адрес.
- **Особистий кабінет:** Перегляд статусу активних та минулих замовлень.
- **Система лояльності (Кешбек):** Клієнти бачать свій накопичений бонусний баланс і можуть використовувати його для часткової або повної оплати наступних замовлень (відсоток налаштовується адміном).

---

## ⚙️ 2. Адмін-панель (Для менеджерів/власників)
Адмін-панель доступна за окремим захищеним посиланням. Для входу потрібні логін та пароль.

**Основний функціонал:**
- **Жива черга замовлень:** Усі нові замовлення з'являються на екрані **моментально** із звуковим сповіщенням ("Тінь!").
- **Управління статусами:** Менеджер може переводити замовлення по етапах: `Нове` ➡️ `В обробці` ➡️ `Відправлено` ➡️ `Виконано` (або `Скасовано`).
- **Авто-сповіщення клієнтів:** При зміні статусу замовлення в адмінці, клієнт автоматично отримує повідомлення в Telegram від бота (наприклад: *"Ваше замовлення відправлено!"*).
- **Каталог:** Додавання, редагування та видалення товарів і категорій. Завантаження фотографій та налаштування цін/акцій.
- **Налаштування закладу:** 
  - Управління відсотком кешбеку.
  - Налаштування графіка роботи (система не дозволить клієнтам замовляти у неробочий час, якщо цю функцію увімкнути).
  - Налаштування реквізитів для оплати.
- **Статистика:** Графіки продажів та підрахунок загального прибутку.

---

## 🤖 3. Telegram Бот (Системні функції)
Telegram-бот виконує роль "зв'язкового" між клієнтом та системою.

- **Сповіщення для адміністраторів:** Щойно клієнт оформлює замовлення, всі адміністратори миттєво отримують повідомлення в Telegram з деталями (Ім'я, телефон, адреса, товари, сума).
- **Сповіщення для клієнтів:** Бот надсилає чек після успішного замовлення та інформує про зміну його статусу (коли менеджер змінює статус в адмінці).
- **Важливе зауваження:** Щоб бот міг надсилати повідомлення клієнту, клієнт **обов'язково** повинен хоча б один раз запустити бота (натиснути кнопку `/start` або "Розпочати"). Це базове правило приватності самого Telegram — бот не може писати людині першим, якщо вона його не активувала.

## Технічні особливості
- Система побудована на сучасних технологіях (FastAPI, React, PostgreSQL).
- Дані захищені (шифрування паролів, JWT-токени).
- Сервер працює цілодобово 24/7.
- Відновлення підключень (WebSockets + Polling) гарантує, що адмін ніколи не пропустить жодного замовлення навіть при нестабільному інтернеті.
