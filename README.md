# 🚀 VreBRO — Інноваційна система доставки їжі в Telegram

**VreBRO** — це сучасна, надшвидка та комплексна екосистема для продажу їжі (ролів, піци, фастфуду тощо) безпосередньо через Telegram Mini App.

Система складається з трьох ключових компонентів:
1. **Telegram Mini App (Вітрина):** Сучасний клієнтський додаток для замовлень, з інтеграцією Кешбеку, Реферальної системи та красивими анімаціями.
2. **Адмін-панель:** Потужна CRM-система для обробки замовлень у реальному часі (WebSockets), аналітики, керування меню, кешбеком та налаштуваннями.
3. **Моніторинг:** Окрема PWA-панель для відстеження навантаження на сервер (CPU, RAM, DB Ping) з автоматичними Telegram-алертами.

---

## 🌟 Основні фічі

- 🛒 **Гнучке Меню:** Підтримка вагових товарів, товарів з опціями (допами), акційних товарів та автоматичних крос-селів ("З цим товаром купують").
- 💰 **Кешбек та Промокоди:** Повноцінна бонусна система. Відсоток кешбеку налаштовується в адмінці, клієнти можуть списувати бонуси при оплаті.
- 📱 **Telegram Bot Інтеграція:** Бот не лише відкриває магазин, а й слугує каналом для PUSH-сповіщень. Клієнти отримують статуси замовлень ("Готується", "В дорозі"), а адміністратори — миттєві сповіщення про нові замовлення.
- ⚡ **Реал-тайм Адмінка:** Не потрібно оновлювати сторінку! Замовлення з'являються на екрані адміністратора миттєво з приємним звуковим сигналом.
- 📈 **Аналітика:** Вбудований дашборд з графіками продажів, топовими товарами та LTV клієнтів.
- 🤖 **AI-Аналітик:** Інтегрований штучний інтелект, який аналізує ваші продажі і дає бізнес-поради українською мовою.

---

## 🛠 Технологічний стек

- **Backend:** Python 3.10+, FastAPI, SQLAlchemy, Aiogram 3.x (для Telegram бота)
- **База Даних:** PostgreSQL (на продакшені) / SQLite (локально)
- **Frontend (Mini App & Admin):** React, TypeScript, TailwindCSS, Vite
- **Deployment:** Render (повністю готовий до CI/CD)

## 🚀 Як запустити проект локально

### 1. Запуск Backend
```bash
# Клонуйте репозиторій
git clone <ваш-репозиторій>
cd VreBRO/backend

# Створіть віртуальне середовище та встановіть залежності
python -m venv venv
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt

# Запустіть сервер
uvicorn main:app --reload --port 8000
```

### 2. Запуск Admin Panel
```bash
cd VreBRO/admin-panel
npm install
npm run dev
```

### 3. Запуск Mini App
```bash
cd VreBRO/miniapp/frontend
npm install
npm run dev
```

## 🌐 Розгортання (Деплой) на Render

Система оптимізована для розміщення на безкоштовних або дешевих тарифах Render.
1. Підключіть репозиторій до Render.
2. Створіть **Web Service**.
3. **Build Command:** `./build.sh` (автоматично збирає React-додатки та встановлює Python-залежності).
4. **Start Command:** `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. Додайте змінні середовища (Environment Variables):
   - `BOT_TOKEN`: Ваш токен бота від BotFather
   - `ADMIN_CHAT_ID`: Ваш Telegram ID (для отримання сповіщень)
   - `SECRET_KEY`: Будь-який секретний ключ (для токенів адмінки)
   - `RENDER_EXTERNAL_URL`: Ваш публічний URL на Render (напр. `https://vrebro.onrender.com`)
